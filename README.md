# Lily the Story 🌸

Website đọc truyện tiểu thuyết & truyện tranh

## Chạy local

```bash
cd lily-story
node server.js
```

Mở: **http://localhost:3000**

## Tính năng

### User
- Đăng ký / Đăng nhập
- Tìm kiếm, lọc theo loại & thể loại
- Yêu thích truyện
- Bình luận
- Lịch sử đọc / Tiếp tục đọc
- Đọc tiểu thuyết (text) & truyện tranh (ảnh)
- Chuyển chương trước/sau, chọn chương, danh sách chương
- Tương thích điện thoại

### Admin
- Thêm / sửa / xóa truyện (gắn nhiều thể loại)
- Upload ảnh bìa
- Thêm chương tiểu thuyết (nhập text + chỉnh font/cỡ/màu)
- Thêm chương truyện tranh (upload nhiều ảnh)
- Thêm admin (cần nhập mật khẩu xác nhận `phanhnguyen666`)
- Khóa / xóa user
- Ẩn / xóa bình luận
